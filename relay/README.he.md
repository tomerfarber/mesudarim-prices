# הקמת השרת בישראל (פעם אחת, כ-10 דקות)

קרפור, חצי חינם וויקטורי מפרסמות את המחירים רק לכתובות בישראל. השרתים של GitHub נמצאים בחו"ל, ולכן המחירים שלהן לא מגיעים. השרת הקטן הזה רץ בחשבון ה-AWS שלכם בתל אביב ומביא את הקבצים בשבילם.

## מה צריך
- חשבון AWS שכבר פתחתם (עם אזור תל אביב מופעל).
- הקובץ `template.yaml` מהתיקייה `relay` בפרויקט mesudarim-prices. אם אין לכם אותו, בקשו מ-Claude לשלוח אותו.

## שלבים
1. נכנסים ל-AWS. בפינה העליונה, ליד שם החשבון, בוחרים את האזור **Israel (Tel Aviv)**.
2. בשורת החיפוש למעלה כותבים **CloudFormation** ונכנסים אליו.
3. לוחצים **Create stack**, ובתפריט שנפתח בוחרים **With new resources (standard)**.
4. בוחרים **Upload a template file**, לוחצים **Choose file** ובוחרים את `template.yaml`. לוחצים **Next**.
5. בשדה **Stack name** כותבים `mesudarim-price-relay`. את שאר השדות לא משנים. לוחצים **Next**.
6. בעמוד הבא לא משנים כלום. לוחצים **Next**.
7. בעמוד האחרון גוללים למטה, מסמנים את התיבה **I acknowledge that AWS CloudFormation might create IAM resources** ולוחצים **Submit**.
8. מחכים עד שהסטטוס משתנה ל-**CREATE_COMPLETE**. זה לוקח כ-2 דקות. אפשר ללחוץ על כפתור הרענון.
9. עוברים ללשונית **Outputs**. יש שם שתי שורות: **FunctionUrl** ו-**RoleArn**. מעתיקים את שני הערכים מהעמודה **Value** ושולחים אותם ל-Claude.

זהו. Claude יחבר אותם לעדכון המחירים, ומאותו יום יגיעו גם המחירים של קרפור, חצי חינם וויקטורי.

## כדאי לדעת
- שני הערכים האלה אינם סיסמאות, ואפשר לשלוח אותם בצ'אט.
- רק העדכון של מסודרים ב-GitHub יכול להשתמש בשרת, והוא יכול להגיע רק לאתרי המחירים של שלוש הרשתות.
- השימוש הצפוי קטן מאוד ונכנס במכסה החינמית החודשית של AWS. התקציב שהגדרתם יתריע אם משהו ישתנה.
- אם הסטטוס הוא **ROLLBACK_COMPLETE** או **CREATE_FAILED**: עוברים ללשונית **Events**, מצלמים את המסך ושולחים ל-Claude. אם כתוב שם ש-`token.actions.githubusercontent.com` כבר קיים, מוחקים את ה-stack, חוזרים לשלב 3, ובשלב 5 משנים את **CreateGitHubProvider** ל-`no`.
